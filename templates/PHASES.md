# Phases

> The ledger of iterative development: one row per phase, oldest first. A phase is an Azure Boards
> **Epic** plus an Area Path; a subject doc (`docs/ARCHITECTURE.md` §7) is a slice of the system.
> One phase touches several subjects and one subject is touched by many phases — **this table is
> the only place the two are joined.** There is no docs folder per phase.
>
> `/discover` appends the row when it creates the Epic; `/retrospective` fills `Shipped` when the
> run ends. Never rewrite a closed row.
